# Project constraints

Project: **Seedlings**, a one-page todo list where each task grows from seed to sprout to bloom.

- Use only `index.html`, `style.css` and `script.js`. No dependencies, no CDN, no build step.
- Use semantic HTML (header, main, section, form, labelled controls).
- The layout must work at about 375px wide and on wide desktop screens, with readable text.
- Every control must work with the keyboard and show a visible focus outline.
- Respect `prefers-reduced-motion`.
- Keep the look hand-made and distinctive: no stock gradients, no emoji icons. Plants are drawn as inline SVG.
- Store data only in the browser's `localStorage`. No accounts, no network requests, no analytics.
- Keep all work inside this project folder. Serve only on localhost.
- Do not install packages, deploy, commit or push unless asked.
- Never put keys, tokens, passwords or private data in files, prompts or screenshots.
- No placeholder or lorem ipsum text.
